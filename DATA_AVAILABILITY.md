# Data availability

Original Fluent CAS/DAT/UDF, mesh topology, native boundary values and cell/face
fields are withheld. UDF transcriptions, constitutive lookup tables, private
offsets/decoder, case configurations and learned checkpoints are also withheld.

Selected aggregate diagnostic results are included. Raw reports, Drive identifiers,
local paths, private notebook outputs and CFD spatial contours are not.
Historical PEMFC reproduction is unavailable from this repository alone.
The synthetic example creates independent analytic data and needs no private file.
Reference PDFs are linked, not rehosted; paper licenses do not cover separate files.
